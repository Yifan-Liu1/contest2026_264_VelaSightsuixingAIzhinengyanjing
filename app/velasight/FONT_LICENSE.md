# VelaSight UI Font

`velasight_font_16_ui.c` contains a converted subset of GNU Unifont 17.0.05:

- Source: `unifont-17.0.05.otf`
- Source URL: https://unifoundry.com/pub/unifont/unifont-17.0.05/font-builds/unifont-17.0.05.otf
- Source SHA-256: `85701ab9b1e251ee16f4df00b13f22eac311d72b7dab427a7d975fe7f5064702`
- Glyph set: ASCII `U+0020..U+007F`, GB2312 level-one 3,755 Chinese characters, and `U+8046`
- Conversion: 16 px, 1 bpp, no prefilter, no kerning
